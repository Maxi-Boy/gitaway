# Проверка интерфейса без Go

Заглушка API с правдоподобными данными и сценарий Playwright: вход, вкладки, меню веток,
перетаскивание с диалогом конфликтов, изменения и коммит, редактор, палитра, телефон.
Нужны Node.js и Playwright с Chromium. На сервере не используется и в бинарник не входит.

    node tools/uicheck/mock.mjs "$PWD/web" 8451 &
    node tools/uicheck/check.cjs        # снимки экрана в tools/uicheck/shots/
    # пароль в заглушке: secret

При изменении API обновите заглушку, иначе сценарий проверяет устаревшие ответы.
